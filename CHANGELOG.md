# Changelog

All notable changes to the Discord Badge Knowledgebase and platform badge history are documented in this file.

## [2.4.0] - 2026-10-18
### Added
- Integrated unified dataset from `PandaDevOfficial/badges-discord` and `mezotv/discord-badges`.
- Cataloged 157 unique verified badges across 10 distinct categories.
- Added 41 customizable Guild Clan tag icons with legacy vs active tier segmentation.
- Documented 10-tier progressive families (Account Age, Game Time, Variety, Streaming, Gifting).
- Added JSON Schema Draft 2020-12 validation suite (`scripts/validate_data.py`).
- Added SHA-256 asset checksum verifier (`scripts/check_assets.py`).
- Integrated Discord User Flag and Application Flag bitfield calculator and decoders.
- Built interactive React + TypeScript + Tailwind digital explorer and profile card simulator.

## [2.3.0] - 2024-09-01
- Documented Discord Nitro gemstone tenure redesign (Bronze, Silver, Gold, Platinum, Diamond, Emerald, Ruby, Opal).
- Preserved 8 pre-2024 legacy gemstone vectors in `assets/subscriptions/legacy/`.

## [2.2.0] - 2024-05-15
- Documented Gifting progression badges (Patron to Legend) for Discord Shop and Wishlists.

## [2.1.0] - 2024-04-17
- Documented platform-wide UI rebranding of 'BOT' tag to 'APP' tag.

## [2.0.0] - 2024-04-10
- Documented experimental Profile Badges 101 activity progression milestones.

## [1.5.0] - 2023-10-05
- Documented temporary pause of Discord Partner Program public application intakes.

## [1.4.0] - 2023-05-03
- Documented username migration and creation of the legacy 'Originally known as' badge.

## [1.3.0] - 2022-12-01

## [1.2.0] - 2022-11-09

## [1.1.0] - 2020-08-19

## [1.0.0] - 2018-10-10
